## What it does

`main.ts` (Node 22, stdlib only) writes one short encouraging text to `/output/entry.txt` — 1–280 characters, UTF-8 — and keeps a copy at `output/entry.txt` for verification.

Run it:

```sh
node main.ts
```

The text is original, written for this bounty: steady words for a nervous reader, a reminder that the next page is only a page, and that the judgment built word by word is worth trusting.
